# Renderings

These are 3D models of the house, saved as dated snapshots so changes can be compared over time.

| Version | Date | What it shows |
|---|---|---|
| [**Baseline**](2026-11-08-baseline/) | Nov 8, 2026 | The house as it is today, before any renovation. This is the reference point for every later version. It matches the updated [floor plan](../floor-plan/). |
| [**Dream plan**](2026-11-08-dream-plan/) | Nov 8, 2026 | [Concept 6](../concepts/2026-11-08-layout-concepts/), the budget-no-object layout, built in the same scene as the baseline with a Today / Dream switch. The garage becomes a sunken living room, the kitchen moves by the deck, and the south bedrooms become a primary suite. |

## Adding a new version

1. Create a new folder named `YYYY-MM-DD-short-name`, for example `2026-11-15-duct-moved` or `2026-12-01-kitchen-concept-a`.
2. Put the updated `index.html`, the snapshot images (using the same view names as the baseline) and a README in it. The README should say what changed compared with the baseline.
3. Add a row to the table above.

Keep the baseline folder unchanged so you can always compare against the starting point.
