## Adding a new version

1. Create a new folder named `YYYY-MM-DD-short-name`, for example `2026-11-20-open-middle-refined`.
2. Put the `index.html`, the plan images and a README in it. The README should say what changed compared with the earlier version.
3. Add a row to the table above.

When a concept is chosen, model it in 3D as a new version under [`../renderings/`](../renderings/) so it can be compared with the baseline.
